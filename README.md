🎨 ThemePalette
A simple and interactive theme preview tool that lets you explore different color combinations and choose the perfect theme for your next web project.

🌐 Live Demo
View ThemePalette:  https://dev-sumit0.github.io/ThemePalette

📌 About the Project
ThemePalette is a lightweight web project created to help developers experiment with different color themes before using them in their own projects.

It provides five predefined color themes that can be switched instantly with a single click. Each theme offers a different combination of background colors, text colors, accents, borders, and shadows.

The idea is simple: preview different color styles, find the one you like, and use it as inspiration for your next website.

✨ Features
🎨 5 Color Themes — Explore Luxury, Modern Tech, Premium Creative, Elegant Copper, and Fresh Emerald.
⚡ Instant Theme Switching — Change the color scheme with a single click.
📱 Responsive Design — Works on desktop and mobile screens.
✨ Smooth Transitions — Enjoy subtle animations and hover effects.
🧩 CSS Variables — Manage and customize theme colors easily.
💎 Modern UI — Clean layout, elegant typography, and subtle background effects.
🖱️ Interactive Controls — Easily preview different color combinations.

Getting Started
You can run this project locally in just a few steps.

1. Clone the Repository
git clone https://github.com/dev-sumit0/ThemePalette.git

2. Open the Project Folder
cd ThemePalette

3. Run the Project
Open the index.html file in your browser.

No additional dependencies or build tools are required.
